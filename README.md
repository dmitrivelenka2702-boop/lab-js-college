# Лабораторна робота з JavaScript

## Предметна область
Коледж

## Опис роботи

У лабораторній роботі створено вебсторінку для представлення
предметної області «Коледж».

Виділено три основні сутності:

1. Студенти
2. Викладачі
3. Навчальні дисципліни

Для кожної сутності створено окрему таблицю,
яка містить сім характеристик.

Перемикання між таблицями реалізовано
за допомогою вкладок (tabs) мовою JavaScript.

## Використані технології

- HTML
- CSS
- JavaScript

Сторонні бібліотеки та фреймворки не використовувалися.

## Структура проєкту

- index.html — структура вебсторінки
- style.css — оформлення вебсторінки
- script.js — JavaScript для роботи вкладок
- README.md — опис проєкту
