# Лабораторна робота №1 з JavaScript

## Предметна область
Коледж

## Опис роботи

У лабораторній роботі створено вебсторінку для представлення предметної області «Коледж».

Виділено три основні сутності:

1. Студенти
2. Викладачі
3. Навчальні дисципліни

Для кожної сутності передбачено окрему таблицю із сімома характеристиками.

## Реалізація JavaScript

Дані про студентів, викладачів і навчальні дисципліни зберігаються у масивах об'єктів у файлі `script.js`.

HTML містить лише структуру таблиць і порожні елементи `tbody`. Рядки таблиць створюються та додаються на сторінку динамічно засобами JavaScript через DOM (`createElement`, `textContent`, `appendChild`).

Перемикання між таблицями також реалізовано мовою JavaScript за допомогою вкладок.

## Використані технології

- HTML
- CSS
- JavaScript

Сторонні бібліотеки, фреймворки та готові рішення не використовувалися.

## Структура проєкту

- `index.html` — структура вебсторінки та порожні контейнери таблиць
- `style.css` — оформлення вебсторінки
- `script.js` — дані, їх динамічний рендеринг і логіка перемикання вкладок
- `README.md` — опис проєкту
